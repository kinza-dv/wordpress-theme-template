## Эта инструкция поможет вам создать новый раздел на сайте (например, "Портфолио", "Услуги", "Отзывы") и сделать для него страницы.

### 🔹 Шаг 1: Добавление нового раздела (типа записей)

1. Откройте файл `inc/post-types.php` вашей темы.
2. Замените `portfolio` и `Портфолио` на свое название (например, `reviews` и `Отзывы`). 

✅ Готово! В меню слева появится новый раздел (например, "Портфолио"), где можно добавлять материалы.

### 🔹 Шаг 2: Создание страниц для раздела

#### 📄 1. Страница со списком всех записей (например, все работы портфолио)

1. Создайте файл `archive-portfolio.php` (если ваш раздел называется portfolio) в корне темы.

```php
<?php get_header(); ?>
<h1>Наши работы</h1>
<?php if (have_posts()) : while (have_posts()) : the_post(); ?>
    <div class="work">
        <h2><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
        <?php the_post_thumbnail(); ?>
        <?php the_excerpt(); ?>
    </div>
<?php endwhile; endif; ?>
<?php get_footer(); ?>
```

2. Страница автоматически откроется по адресу вашсайт.ru/portfolio.

#### 📝 2. Страница одной записи (например, отдельная работа)

1. Создайте файл `single-portfolio.php` (если раздел называется portfolio) в корне темы.

```php
<?php get_header(); ?>
<article>
    <h1><?php the_title(); ?></h1>
    <?php the_post_thumbnail(); ?>
    <?php the_content(); ?>
</article>
<?php get_footer(); ?>
```
